!!! note "Namespace must match Mavrick' deployment"
    Create the secret in the same namespace where Mavrick runs. The `-n mavrick` flag in the **Mavrick Helm** tab and `-n default` in the **Robusta Helm** tab are examples: use the namespace you installed the chart into. The Mavrick install guide passes no `-n`, so it installs Mavrick into your kubectl context's namespace, `default` unless you set another. `helm list -A` shows each release's namespace. If the secret is not in that namespace, the Mavrick pod does not start: it stays in `CreateContainerConfigError` and its events show `Error: secret "<name>" not found`.
